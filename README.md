# Kajer Bazar Android App

প্রাথমিক Android ডেমো অ্যাপ। বাংলা হোম স্ক্রিন ও নমুনা কাজের তালিকা অন্তর্ভুক্ত।

## APK build
GitHub Actions-এর Build Kajer Bazar APK workflow চালালে app/build/outputs/apk/debug/app-debug.apk তৈরি হবে। বিস্তারিত বাংলা নির্দেশনা BUILD_APK_BN.md-এ।

## এখনো নেই
- বাস্তব ব্যবহারকারী অ্যাকাউন্ট ও লগইন
- কাজ প্রকাশ, সম্পাদনা ও ম্যানেজমেন্ট
- সার্ভার/ডাটাবেস
- bKash/Nagad পেমেন্ট ও কমিশন সংগ্রহ

পেমেন্টের জন্য অনুমোদিত মার্চেন্ট অ্যাকাউন্ট ও নিরাপদ সার্ভার প্রয়োজন। গোপন কী Android অ্যাপে রাখা যাবে না।
